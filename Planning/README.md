# Tellurian.Trains.Schedules.Planning

Planning utilities for creating layouts, timetables and schedules for model railway operations.

## Installation

```bash
dotnet add package Tellurian.Trains.Schedules.Planning
```

This will also install `Tellurian.Trains.Schedules.Model` as a transitive dependency.

## Purpose

This package provides utilities for planning and building:
- **Layouts** - Track infrastructure with stations, tracks, and stretches
- **Timetables** - Train schedules with station calls and timings
- **Schedules** - Complete operation schedules with vehicle assignments and driver duties

It serves as the foundation for planning applications that create and manage model railway schedules.
