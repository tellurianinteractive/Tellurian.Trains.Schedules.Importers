Settings control how the current layout's timetable is calculated, drawn and validated. They
are saved with the layout, so each layout keeps its own settings.

## General

Name the layout and choose its operating window. Use **days** when the timetable spans several
named operating days; otherwise it is treated as a single session. The start and end times bound
the graphical timetable's time axis and may run to or past midnight.

## Graphic timetable

Control the appearance of the graphical timetable: the orientation of the time axis, the spacing
of stations and tracks, and which labels (arrival/departure minutes, train category, company) are
shown.

## Time and speed

Set the fast-clock speed and map speed classes to scale and real speeds. The default station
times (minimum stop, loco run-around, train clearance) are used when calculating timings for
stations that do not override them.

## Validation

Choose which checks run and the thresholds they use. Switching a check off suppresses its
messages without removing the underlying data.

## Integration

Keys and settings for connecting to external services, such as the module registry.
