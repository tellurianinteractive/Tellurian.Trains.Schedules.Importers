Der Reiter **Regionen** definiert die Ziele *außerhalb* Ihrer Anlage – die inländischen Regionen und
fremden Länder, in die Wagen geleitet werden können. Regionen dienen der Leitung von Wagenströmen: Sie erlauben es dem
Zielhinweis eines Zuges anzugeben, wohin seine Wagen jenseits der modellierten Bahn unterwegs sind.

### Was eine Region ist

Jede Region hat:

- einen **Namen**, geschrieben in der Standardsprache der Anlage und überall angezeigt, wo auf die Region verwiesen wird,
- ein **Land**, zu dem sie gehört – eine neue Region erhält das Standardland der Anlage, aber eine Region,
  die für ein ausländisches Ziel steht, kann stattdessen auf dieses Land gesetzt werden,
- eine **Hintergrundfarbe**, mit der die Region in Hinweisen als farbiges Feld dargestellt wird (die Textfarbe wird
  automatisch kontrastiert, damit sie lesbar bleibt).

### Wie Regionen verwendet werden

Eine Region ist für sich genommen nur eine Bezeichnung. Sie erhält Bedeutung, sobald sie einem
**Bahnhof** zugeordnet wird – normalerweise einem **Schattenbahnhof**, einem Endbahnhof, der externe Bahnhöfe und die
Welt jenseits der modellierten Bahn darstellt. Ein Bahnhof kann keiner, einer oder mehreren Regionen zugeordnet sein;
gewöhnliche Bahnhöfe brauchen selten eine.

Ist ein Güterziel auf *Regionen einschließen* gesetzt, listet der Zielhinweis für diesen Bahnhof
dessen Regionen als farbige Felder auf – und sagt dem Bediener, dass dorthin gebrachte Wagen in diese
Regionen oder Länder weiterlaufen.

Definieren Sie die benötigten Regionen hier und ordnen Sie sie dann im Reiter
**Betriebsstellen** Ihren Schattenbahnhöfen zu.

### Regionen verwalten

Die Liste zeigt jede Region als farbiges Feld neben ihrem Namen und Land.

- **Neu hinzufügen** legt eine Region an. Geben Sie einen Namen an, wählen Sie das Land und eine Farbe aus der
  Palette.
- **Bearbeiten** ändert Name, Land oder Farbe einer Region.
- **Löschen** entfernt eine Region. Das wird blockiert, solange einem Bahnhof die Region zugewiesen ist – entfernen Sie
  die Zuordnung zuerst im Reiter **Betriebsstellen**.
- **Standardregionen** fügt die Standardmenge von Regionen hinzu, benannt in der Standardsprache der Anlage und
  praktisch beim Beginn einer neuen Anlage.

Regionen werden mit der Anlage gespeichert, und dieser Katalog ist die Quelle der Regionsauswahl, die beim Bearbeiten
eines Bahnhofs angezeigt wird.
