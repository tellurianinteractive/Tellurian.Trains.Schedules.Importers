I think we can simplify the wagon order reversal. This is only dependent on track stretch direction forward or backward. If the first train in a schedule starts on a forward track stretchs, this implies that on all following forward track stretches, wagons are ordered as defined, and on backwards track stretches they are in reverse order. If the first train in a schedule starts backwards, all backwards track stretches show wagons ordered as defined, and on forward track stretches wagons are ordered in reverse. The purpose is to make it easy to define the order of the wagons, how to set up wagons for the first train in the schedule.

We can generalise the WagonSet.Wagons to be ScheduledOject.Units, for a Locomotive the units are locos in consist, for a TrainSet the wagons in it, for a WagonSet as is, for CargoOnly and CargoFlow empty for now and not editable.
