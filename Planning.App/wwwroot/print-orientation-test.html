Page 1 — Mechanism A: @page a4l { size: A4 landscape }

In print preview (Ctrl/Cmd+P) this page should be wider than tall (landscape). If it is, the named-page approach works in your browser — the app's reports will print landscape.

Page 2 — Mechanism B (fallback): page-orientation: rotate-left

Paper stays A4 portrait but the content is rotated 90°. Use this fallback only if Page 1 came out portrait. The text here should read sideways relative to the paper edge.
